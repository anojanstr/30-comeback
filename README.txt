30 — COMEBACK (PWA privée)

Contenu :
- index.html : application
- manifest.webmanifest : paramètres d'installation
- sw.js : fonctionnement hors ligne après premier chargement
- icons/ : icônes iPhone

Données :
- Stockées dans localStorage du navigateur sur l'appareil.
- Aucun compte, aucun serveur de données, aucune synchronisation iCloud.
- Ne stocke pas de mots de passe ni de données bancaires sensibles.
- Pense à exporter / sauvegarder manuellement tes données si tu changes d'iPhone ou de navigateur.

Installation iPhone :
1. Héberge le dossier sur un site HTTPS (GitHub Pages gratuit convient).
2. Ouvre l'adresse du site dans Safari sur l'iPhone.
3. Appuie sur Partager > Sur l'écran d'accueil.
4. Active « Ouvrir comme app » si l'option apparaît, puis Ajouter.

Ce dossier est prêt pour l'hébergement statique. L'application n'est pas publiée ni hébergée automatiquement par ce fichier.
